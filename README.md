# ✝️ Igreja Batista Viva em Piedade — Landing Page

Site institucional da **Igreja Batista Viva em Piedade (IBVIVA)**, criado para dar as boas-vindas a quem visita, contar um pouco da nossa história e facilitar o contato de qualquer lugar do mundo — em português, inglês ou espanhol.

Mais do que um site, essa página foi pensada para ser um convite: um lugar simples, bonito e acolhedor, do jeitinho que a nossa igreja é.

---

## 📖 Sobre o projeto

A **Igreja Batista Viva em Piedade** fica em Jaboatão dos Guararapes (PE) e queria um espaço digital que refletisse quem somos: uma comunidade viva, acolhedora e conectada com as pessoas. Esta landing page reúne em um só lugar:

- Nossa história e identidade
- Um mural com fotos da igreja
- Localização com acesso direto ao Google Maps
- Contato rápido por e-mail e WhatsApp
- Nossas redes sociais oficiais
- Suporte a três idiomas e aos temas claro/escuro

Tudo isso com um visual moderno, leve e responsivo — funciona bem no computador, no tablet e no celular.

---

## ✨ Funcionalidades

- 🎥 **Vídeo de abertura** inspirado nas fotos reais da igreja
- 🖼️ **Mural de fotos** moderno, com frases e insights leves para inspirar quem visita
- 🌗 **Tema claro e escuro**, com transição suave
- 🌍 **Três idiomas**: Português (BR), Inglês e Espanhol
- 📍 **Localização** com link direto para o Google Maps
- 💬 **Contato rápido pelo WhatsApp**, já com mensagem pronta ("Olá! Vim pelo site da igreja")
- 📧 Contato por e-mail
- 📱 **Redes sociais**: Instagram, Facebook e YouTube
- 📐 **Layout 100% responsivo**: PC, tablet e celular
- 🎬 Animações suaves ao rolar a página, sem exageros

---

## 🎨 Identidade visual

A identidade visual do site nasce da nossa própria logo: uma **cruz azul com contorno amarelo**. Essas duas cores guiam toda a paleta da página — o azul transmite confiança e serenidade, e o amarelo destaca os pontos de atenção, como botões e chamadas para ação.

## 🚀 Como rodar o projeto localmente

```bash
# Clone este repositório
git clone https://github.com/seu-usuario/ibviva-landing-page.git

# Acesse a pasta do projeto
cd ibviva-landing-page

# Instale as dependências 
npm install

# Rode o projeto localmente
npm run dev
```

Depois é só abrir [http://localhost:3000](http://localhost:3000) (ou a porta indicada no terminal) no navegador. 🎉
